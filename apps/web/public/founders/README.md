# Founder headshots

Drop each founder's headshot here; it's served at the site root and shown on
the landing page. Accepted extensions: .jpg, .jpeg, or .png (any one works).

- jaanhvi.(jpg|jpeg|png)   → Jaanhvi Hiremath
- prasad.(jpg|jpeg|png)    → Prasad Anaokar
- reva.(jpg|jpeg|png)      → Reva Surve

Square images (e.g. 400×400) look best — they're cropped to a circle.
If a file is missing, that card falls back to the founder's initials.
After adding, restart `pnpm dev:web` and hard-refresh (Cmd+Shift+R).
